# 🎓 LearnSphere – Online Learning Platform

LearnSphere is a full-stack e-learning platform inspired by websites like Smart Programming.  
It allows students to register, login, browse courses, enroll, and manage their learning journey.

---

## 🚀 Features

### 👤 User Management
- User Registration
- User Login
- Forgot Password (OTP based)
- Reset Password
- Role-based users (STUDENT / ADMIN)

### 📚 Course Management
- Categories
- Courses (Free & Paid)
- Course Filters:
  - Category
  - Price (FREE / PAID)
  - Level (BEGINNER / INTERMEDIATE / ADVANCED)
  - Popularity (LOW / MEDIUM / HIGH)
  - Course Type

### 📝 Enrollment
- Student enrollment into courses
- View enrolled courses (Student Dashboard)
- View enrollments by user or course

### 📊 Student Dashboard
- User profile
- Enrolled courses
- Course listing with filters
- Logout functionality
